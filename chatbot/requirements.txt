# No third-party packages required — the whole app (demo AND live Power BI
# Service mode) runs on the Python standard library.
#
#   python3 backend/app.py
#
# Live Power BI Service mode (POWERBI_MODE=live) uses only urllib for the Entra
# OAuth2 flow and the Power BI REST API, so there is nothing to pip install.
#
# The AI planner can optionally use the Anthropic API (calls the HTTPS endpoint
# with the standard library — the `anthropic` package is not required):
#   export ANTHROPIC_API_KEY=sk-ant-...
#   export CHATBOT_LLM_MODEL=claude-sonnet-5   # optional
